拾日使用支持

联系邮箱：wwheyg@gmail.com。

反馈问题时请附上 iPhone 型号、iOS 版本、拾日版本和简短操作步骤。截图前请遮住私人内容；不要发送 API Key、密码、验证码或完整备份。

无需模型也能使用

文字、照片及 PDF 记录、关键词搜索、生活回顾、收支账单、密码库与手动项目统计无需配置模型。未配置可用模型时，搜索默认使用关键词。

配置可选 AI

在设置的大模型编辑页添加服务、HTTPS API 地址、模型名称和你自己的 API Key。密钥与地址需对应同一平台。AI 调用费用和内容处理方式取决于服务商。

备份与换机

在设置中导出“记录与图片”，将文件保存在你控制的位置；换机后导入拾日备份。普通备份包含记录、照片、PDF 附件、留言和统计，不含 API Key 或密码库；导入前请查看核验与恢复选项。密码库需在其设置中单独导出加密备份，并保管解锁密码。当前没有应用内自动同步。卸载前请先导出，备份文件可能包含完整私人内容。

项目统计

在生活回顾的汇总页面管理项目。随手记中的项目加号直接添加数值，不生成生活文章。已设置单位的项目有数值后会锁定；原先未设置单位的项目可以补充单位。

语音与权限

首次使用麦克风时允许语音识别与麦克风权限。设备支持时本地识别，否则可能需要 Apple 联网服务；也可使用键盘输入。

删除

生活记录详情中点击编辑后可以删除记录。设置中可清空记录；单独导出的文件和第三方已处理的请求需分别管理。

隐私与 AI 授权

可将记录设为隐私，阻止它参与 AI 整理、AI 搜索和记忆来源；本地统计与备份仍可包含它。AI 授权可在设置中撤回；撤回或设为隐私不会删除服务商已经处理的内容。

收支与定期缴费

账单支持支出、收入及退款；退款抵减支出，收入单独统计。定期缴费只是计划与本地提醒，需要点击完成并确认后才生成支出，不会自动支付。提醒需要系统通知权限。

密码库

在设置入口创建独立密码库，可用解锁密码进入，并选择开启系统生物识别。支持多级分组、搜索、归档及回收站；编辑后才可修改项目。密码库不参与 AI 或普通记录备份。开发者无法找回解锁密码，请保管密码与独立加密备份。

附件与回看留言

随手记可添加 PDF 附件及拍照，保存前可查看附件占位，保存后可打开预览。记录详情支持给过去的自己写留言；留言仅供自己查看，不是公开评论。
