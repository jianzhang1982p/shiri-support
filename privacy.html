拾日隐私政策

更新日期：2026 年 11 月 10 日。适用于拾日生活手记 1.0.0 正式版本。

运营者与联系

拾日生活手记由 XiaoJian Zhang 提供。隐私与产品支持邮箱：wwheyg@gmail.com。

本地记录与备份

拾日在设备上保存你创建的文字、照片、分类、收藏、消费与项目数值、草稿及记忆资料。无需注册拾日账号；当前版本没有开发者提供的记录云同步服务。iOS 整机备份由系统和用户设置管理。

你可主动导出包含记录、图片、统计与记忆的 JSON 备份，或导入已有备份。导出文件可被读取，请妥善保存。应用备份不含模型 API Key。

可选 AI 服务

你可配置第三方模型服务。使用 AI 整理时，应用可能将相关原文、所选照片、分类、项目说明、自定义文字处理要求及适用的表达偏好发送至你配置的接口。AI 搜索先在本地筛选，再可能发送问题、相关片段、摘要和记忆供服务核对；无需模型的本地操作不会因此发送给 AI。

请求从设备直接发送至配置的 HTTPS 服务。API Key 通过该接口的认证请求头发送，用于服务商识别账户。连接测试发送固定示例，也可能产生服务商费用。

服务商是否保留数据、用于训练、将请求关联其账户，以及处理地区与保存时间，取决于其协议和你的账户设置。自定义地址也可能由代理运营者接收数据；请先核对实际接收方。拾日无法替第三方承诺零留存或不用于训练。

应用在向第三方 AI 发送内容前说明接收方与用途，并取得明确同意；你可拒绝并继续使用本地功能，也可在设置中撤回后续发送授权。授权按实际接收地址和告知版本保存，地址改变后需重新同意。撤回会关闭 AI 自动整理，并阻止后续 AI 发送；已经发出的内容需依据服务商规则处理。

语音与照片

语音输入使用 Apple 的语音识别框架。设备支持时使用设备内识别，否则音频可能由 Apple 联网处理；拾日不保存原始录音文件。开始录音前会请求系统权限并显示录音状态。

照片通过系统照片选择器由你主动选择。只有你选择的照片进入记录；进行带图 AI 整理时，这些照片可能发送至所配置的模型接口。

安全与密钥

记录文件使用系统数据保护能力。API Key 保存在系统钥匙串中，不写入记录备份。删除模型配置会移除对应的钥匙串密钥；若担心密钥已泄露，请同时在服务商处撤销。安全措施无法保证设备、导出文件或第三方服务绝对安全。

删除与选择

你可逐条编辑、删除生活记录和图片，管理独立项目数值、长期记忆及模型配置，也可在设置中清空生活记录、图片、项目数值与长期记忆。已导出、系统备份或已发送给第三方的内容不随本地删除自动消失，需分别管理。应用无拾日账户，因此没有独立的账户注销流程。

广告与支持

当前版本不包含广告或跨应用追踪 SDK，也不出售用户记录。你主动发邮件求助时，邮件服务会处理你提供的地址和邮件内容；请不要发送 API Key、密码或完整私人记录。

公开支持与隐私网页由 GitHub Pages 托管。访问网页时，托管方可能为提供页面、安全与运行维护处理 IP 地址和访问日志；详情见 GitHub 隐私声明。这些网页不嵌入分析、广告或第三方追踪脚本。

政策更新

数据处理方式发生变化时会更新本政策；新增的数据共享用途应在实施前重新告知。请通过 wwheyg@gmail.com 联系开发者行使适用的数据权利或反馈问题。
