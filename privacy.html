拾日隐私政策

更新日期：2026 年 11 月 13 日。适用于拾日生活手记 1.0.1；旧版中尚未提供的功能不适用。

本地记录与备份

拾日在设备上保存你创建的文字、照片、PDF 附件、回看留言、分类、收藏、收支与项目数值、定期缴费计划、草稿及记忆资料。无需注册拾日账号；当前版本没有开发者提供的记录云同步服务。iOS 整机备份由系统和用户设置管理。

你可主动导出包含记录、图片、附件、留言、统计与记忆的 JSON 备份，或导入已有备份。导出文件可被读取，请妥善保存。普通记录备份不含模型 API Key 或密码库。导入前可核验内容，恢复前的本地副本也可能继续保留在设备中，直至下一次恢复替换或移除应用；请留意本地和导出文件的安全。

可选 AI 服务

你可配置第三方模型服务。使用 AI 整理时，应用可能将相关原文、所选照片、分类、项目说明、自定义文字处理要求及适用的表达偏好发送至你配置的接口。AI 搜索先在本地筛选，再可能发送问题、相关片段、摘要和记忆供服务核对；无需模型的本地操作不会因此发送给 AI。

请求从设备直接发送至配置的 HTTPS 服务。API Key 通过该接口的认证请求头发送，用于服务商识别账户。连接测试发送固定示例，也可能产生服务商费用。

服务商是否保留数据、用于训练、将请求关联其账户，以及处理地区与保存时间，取决于其协议和你的账户设置。自定义地址也可能由代理运营者接收数据；请先核对实际接收方。拾日无法替第三方承诺零留存或不用于训练。

选择 MiniMax 中国大陆接口时，内容可能在中国大陆处理。MiniMax 公布的条款允许将去标识化后的输入及对应输出用于服务优化、统计分析、问题排查和安全风控；这不等于零留存或不训练承诺。请核对调用时适用的 MiniMax 用户协议及隐私政策，并仅发送你有权提供的内容。

应用在向第三方 AI 发送内容前说明接收方与用途，并取得明确同意；你可拒绝并继续使用本地功能，也可在设置中撤回后续发送授权。授权按实际接收地址和告知版本保存，地址改变后需重新同意。撤回会关闭 AI 自动整理，并阻止后续 AI 发送；已经发出的内容需依据服务商规则处理。

隐私记录与附件

标为隐私的记录不用于 AI 整理、AI 搜索或记忆来源；仍可用于本地查看、统计及你主动导出的备份。设为隐私不能撤回此前已发送给服务商的内容。PDF 附件用于本地保存、预览与备份，不会因添加附件而自动发送给模型。

密码库

密码库是独立的本地加密模块，用于保存你输入的账号、密码、网址、备注和分组。它不参与模型整理、搜索或记忆，不同步至开发者服务器。解锁密码用于保护加密数据；可选 Face ID 或 Touch ID 通过系统验证并使用钥匙串保护的解锁材料，应用不会读取或保存面部、指纹原始数据。

密码库支持独立的加密备份，不包含在普通记录 JSON 备份中。请妥善保管解锁密码和备份，开发者无法代为重置解密密码或恢复明文。复制敏感字段会临时写入系统剪贴板，并按应用的安全规则清理；请留意设备上其他应用的剪贴板行为。密码库按所设间隔自动锁定，普通记录的清空操作与密码库分开管理。

定期缴费与通知

账单和收支由你输入、确认或依据记录整理。拾日不连接银行账户，不自动读取其他应用的订阅，也不执行支付、扣款或证券交易。开启缴费提醒时会请求系统通知权限，提醒由设备本地安排；你可以在系统设置中关闭通知。完成缴费需要你确认后才生成支出记录。

语音与照片

语音输入使用 Apple 的语音识别框架。设备支持时使用设备内识别，否则音频可能由 Apple 联网处理；拾日不保存原始录音文件。开始录音前会请求系统权限并显示录音状态。

照片通过系统照片选择器由你主动选择，也可在授予相机权限后拍摄。只有你选择的照片进入记录；进行带图 AI 整理时，这些照片可能发送至所配置的模型接口。

安全与密钥

记录文件使用系统数据保护能力。API Key 保存在系统钥匙串中，不写入记录备份。删除模型配置会移除对应的钥匙串密钥；若担心密钥已泄露，请同时在服务商处撤销。安全措施无法保证设备、导出文件或第三方服务绝对安全。

删除与选择

你可逐条编辑、删除生活记录和图片，管理独立项目数值、长期记忆及模型配置，也可在设置中清空生活记录、图片、项目数值与长期记忆。已导出、系统备份或已发送给第三方的内容不随本地删除自动消失，需分别管理。应用无拾日账户，因此没有独立的账户注销流程。

广告与支持

当前版本不包含广告或跨应用追踪 SDK，也不出售用户记录。你主动发邮件求助时，邮件服务会处理你提供的地址和邮件内容；请不要发送 API Key、密码或完整私人记录。

公开支持与隐私网页由 GitHub Pages 托管。访问网页时，托管方可能为提供页面、安全与运行维护处理 IP 地址和访问日志；详情见 GitHub 隐私声明。这些网页不嵌入分析、广告或第三方追踪脚本。

政策更新

数据处理方式发生变化时会更新本政策；新增的数据共享用途应在实施前重新告知。请通过 wwheyg@gmail.com 联系开发者行使适用的数据权利或反馈问题。
